# Protokoll 33 über das Schiedsverfahren

| 0.110 |  |  |
|---|---|---|

Protokoll 33

über das Schiedsverfahren

1) Wird ein Streitfall einem Schiedsverfahren überwiesen, so werden, sofern die Streitparteien nichts anderes beschliessen, drei Schiedsrichter ernannt.

2) Von beiden Seiten eines Streitfalls wird innerhalb von 30 Tagen je ein Schiedsrichter ernannt.

3) Die auf diese Weise bestimmten Schiedsrichter einigen sich auf einen Schiedsrichterobmann, der die Staatsangehörigkeit einer Vertragspartei, nicht jedoch dieselbe wie die der beiden ernannten Schiedsrichter besitzt. Können letztere sich nicht innerhalb von zwei Monaten nach ihrer Ernennung auf den Schiedsrichterobmann einigen, so wird dieser von ihnen aus einer vom Gemeinsamen EWR-Ausschuss aufgestellten Liste von sieben Personen ausgewählt. Der Gemeinsame EWR-Ausschuss erstellt und überprüft diese Liste nach Massgabe seiner Geschäftsordnung.

4) Sofern die Vertragsparteien nichts anderes beschliessen, erlässt das Schiedsgericht seine Verfahrensordnung. Es trifft seine Entscheidungen durch Mehrheitsbeschluss.
