# Protokoll 7 über mengenmässige Beschränkungen, die Island beibehalten darf

| 0.110 |  |  |
|---|---|---|

Protokoll 7

über mengenmässige Beschränkungen,  
die Island beibehalten darf

Unbeschadet von Art. 11 des Abkommens kann Island für die nachstehend aufgeführten Waren mengenmässige Beschränkungen beibehalten:

| HS-Position | Warenbezeichnung |
|---|---|
| 96.03 | Besen, Bürsten und Pinsel (einschliesslich solcher, die Teile von Maschinen, Apparaten oder Fahrzeugen sind), von Hand zu führende mechanische Fussbodenkehrer ohne Motor, Mops und Staubwedel; Pinselköpfe; Kissen und Roller zum Anstreichen; Wischer aus Kautschuk oder ähnlichen geschmeidigen Stoffen: |
|  | - Zahnbürsten, Rasierpinsel, Haarbürsten, Nagelbürsten, Wimpernbürstchen und andere Bürsten zur Körperpflege, einschliesslich Bürsten, die Teile von Apparaten sind: |
| 96.03 29 | -- andere |
| 96.03 29 01 | -- mit Rücken aus Kunststoff |
| 96.03 29 09 | -- andere |
