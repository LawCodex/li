# Protokoll 35 zur Durchführung der EWR-Bestimmungen

| 0.110 |  |  |
|---|---|---|

Protokoll 35

zur Durchführung der EWR-Bestimmungen

In Anbetracht der Tatsache, dass dieses Abkommen auf die Errichtung eines homogenen Europäischen Wirtschaftsraums abzielt, der auf gemeinsamen Regeln beruht, ohne dass von einer Vertragspartei verlangt wird, einem Organ des Europäischen Wirtschaftsraums Gesetzgebungsbefugnisse zu übertragen sowie

in Anbetracht der Tatsache, dass dies folglich durch nationale Verfahren erreicht werden muss -

## Einziger Artikel

Für Fälle möglicher Konflikte zwischen durchgeführten EWR-Bestimmungen und sonstigen gesetzlichen Bestimmungen verpflichten sich die EFTA-Staaten, nötigenfalls eine gesetzliche Bestimmung des Inhalts einzuführen, dass in diesen Fällen die EWR-Bestimmungen vorgehen.
